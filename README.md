# Portfolio

My personal portfolio website: Thota Supraja Sandhya, Computer Science student focused on software engineering.

Built with plain HTML, CSS and JavaScript. No build step or dependencies.

## Run it locally
Open `index.html` in a browser.

## Host it on GitHub Pages
1. Push these files to a repository.
2. Go to Settings > Pages.
3. Under "Build and deployment", choose "Deploy from a branch", select the `main` branch and the `/ (root)` folder, then save.
4. Your site will be live at `https://suprajasandhya.github.io/<repository-name>/`.
